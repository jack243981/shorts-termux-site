Política de Privacidade

Última atualização: 4 de outubro de 2026

1. Sobre o Shorts Termux

O Shorts Termux é uma ferramenta pessoal utilizada para organizar e publicar vídeos curtos criados pelo próprio usuário.

2. Dados utilizados

O aplicativo utiliza somente as informações necessárias para autenticar o usuário e realizar as ações de publicação autorizadas pelo próprio usuário.

3. TikTok

Quando o usuário conecta sua conta do TikTok, o Shorts Termux utiliza as permissões concedidas pelo usuário para realizar ações de publicação de conteúdo.

4. Armazenamento

Os vídeos são armazenados localmente no dispositivo do usuário. O Shorts Termux não vende nem comercializa dados pessoais.

5. Compartilhamento

O aplicativo não vende dados pessoais. Informações podem ser transmitidas aos serviços utilizados para executar uma ação solicitada pelo usuário.

6. Segurança

O usuário é responsável por proteger seu dispositivo, suas credenciais e suas contas conectadas.

7. Contato

Para questões relacionadas à privacidade, o usuário pode entrar em contato com o responsável pelo projeto.
