Shorts Termux

O Shorts Termux é uma ferramenta pessoal para automatizar a publicação de vídeos curtos criados pelo usuário.

Integrações

O projeto pode utilizar serviços de publicação de conteúdo, incluindo o TikTok, para permitir que o usuário publique seus próprios vídeos.
